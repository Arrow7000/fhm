A little orientation

FHM, in a minute

FHM is a functional language with Hindley–Milner type inference, custom datatypes, and annotated polymorphic recursion. Write a few definitions, then finish with the expression you want to evaluate.

A function

let id = \x -> x

No signature needed. Hover over a name to see its inferred type.

A signature

let id : {a} a -> a = \x -> x

The variable a is also in scope inside the function's body.

Data & patterns

type Maybe a = Just a | Nothing

Use match value with and | Just x -> … to inspect a value.

Recursion

Definitions can call themselves and each other. Add a complete signature when a recursive call needs a different type.
