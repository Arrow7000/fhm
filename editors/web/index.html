FHM quick reference

A program is a sequence of type and let definitions followed by one expression. Running the program evaluates that expression. Types are inferred; annotations are optional and checked.

let id = \x -> x Definition; the type ∀ a. a → a is inferred
let id : {a} a -> a = \x -> x Annotated definition; a scopes over the body
\(n : Int) -> n + 1 Annotated lambda parameter
type Maybe a = Just a | Nothing Algebraic data type
match m with | Just x -> x | Nothing -> 0 Pattern match; must be exhaustive
let x = 1 in x + 1 Local definition
if b then 1 else 2 Conditional
1 :: [2, 3], (1, True) Lists and pairs
+ - < Built-in Int operators
-- …, {- … -} Comments

Definitions may refer to each other in any order. A recursive call at a different type (polymorphic recursion) needs a full annotation.
